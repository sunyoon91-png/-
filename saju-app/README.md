# 미소년 사주

생년월일시를 입력하면 사주팔자(년주/월주/일주/시주)와 오행 비율을 계산하고,
일간(日干)에 따라 매칭되는 미소년 캐릭터로 결과를 의인화해서 보여주는 웹앱입니다.

## 실행

```bash
npm install
npm run dev
```

## 기술 스택

- React + Vite + Tailwind CSS v4
- 사주 계산: 외부 API 없이 순수 JS 로직 (`src/logic/sajuCalculator.js`)
- 만세력 데이터: 60갑자·오행 매핑(`src/data/ganzhi.js`), 절기 근사 테이블(`src/data/solarTerms.js`)
- 캐릭터 프리셋: 10천간 기준(`src/data/characters.js`)
- 이미지 저장: html2canvas

## 계산 로직 개요

- **일주**: 1900-01-31(갑진일)을 기준일로 60갑자 순환 계산
- **연주**: 입춘(2/4 근사)을 기준으로 사주상의 해를 판단, `(year-4) % 10 / % 12`
- **월주**: 절기 근사 경계일 테이블로 월지 결정 + 오호둔(五虎遁) 공식으로 월간 계산
- **시주**: 오서둔(五鼠遁) 공식으로 일간에 따른 시간 계산, 시간을 모르면 생략
- **오행 비율**: 8글자(4기둥 × 천간/지지)의 오행 분포를 백분율로 환산

> 절기는 연도별로 ±1일 정도 변동하지만, 외부 천문 API 없이 계산하기 위해
> 대표(평균) 날짜를 사용합니다. 절기 경계일 근처 출생자는 실제 만세력과
> 결과가 다를 수 있습니다. 재미로 보는 콘텐츠입니다.
